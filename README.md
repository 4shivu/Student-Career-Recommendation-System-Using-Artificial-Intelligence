# Student Career Recommendation System Using Artificial Intelligence

## 📌 Project Description
This project is a web-based Student Career Recommendation System that uses Artificial Intelligence concepts to suggest suitable career paths for students based on their interests, skills, and preferences.

The goal of this system is to help students make better career decisions by analyzing their inputs and providing relevant suggestions.

---

## 🚀 Features
- Simple and user-friendly interface  
- Career suggestions based on input data  
- Fast and lightweight web application  
- Easy to use for students  

---

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript
